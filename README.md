# C and C++ Practice

A simple repository to store my C and C++ practice programs, exercises, and code snippets.

## 📂 Structure

* `/c_program` - C language exercises (pointers, memory management, etc.)
* `/cpp_program` - C++ language exercises (OOP, STL, etc.)

## 🛠️ How to Run

### Run a C Program:
```bash
gcc file.c -o program
./program
```

### Run a C++ Program:
```bash
g++ file.cpp -o program
./program
```
